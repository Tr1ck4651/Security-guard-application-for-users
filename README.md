## Описание
Система контроля и управления доступом с функциями для администраторов и вахтеров. Включает в себя управление сотрудниками, обработку заявок на пропуск, эмуляцию работы турникетов и ведение статистики.

## Учетные данные по умолчанию
### Администратор
- Логин: admin
- Пароль: 123
- Секретное слово: 123

### Вахтер
- Логин: guard
- Пароль: 123
- Секретное слово: 123

## Эмулятор
Для запуска эмулятора:
1. Войдите в систему как администратор или вахтер
2. Нажмите кнопку "Запустить эмулятор"
3. Для запуска/остановки эмулятора используйте пароль: 1234

## Примечания
- При первом запуске будут созданы необходимые JSON файлы для хранения данных
- Все данные хранятся локально в JSON файлах
- Для корректной работы эмулятора необходимо наличие одобренных заявок на пропуск
